# Простые правила

1. **День** = календарь (`/`). English каждый день одинаковый.
2. **Пн и чт** = фокус на одном времени в говорении. Остальные дни = обычный разговор + лёгкие правки.
3. **Неделя** = одна цель по коду (сейчас W02: сдать async-Дз + IO/CPU demo).
4. **Чт** = проверка: коммит/ревью.
5. **Вс** = итог одной фразой.
6. Пропуск дня → просто продолжить завтра.
